# Desafio API Pessoas

API REST desenvolvida em C# / ASP.NET Core (.NET 8) para gerenciamento de pessoas.

Projeto desenvolvido como parte de um desafio técnico.

## Tecnologias
- C#
-.NET 8
- ASP.NET Core Web API
- JWT Authentication
- Swagger / OpenAPI

## Funcionalidades
- Autenticação com JWT
- Cadastro de pessoas
- Consulta por ID
- Listagem de pessoas
- Consulta por UF
- Atualização de pessoas
- Exclusão de pessoas

## Testando a aplicação manualmente
Clone o repositório:
```bash
git clone https://github.com/n00bia/desafio-api-pessoas.git
```
Abra o projeto no Visual Studio e execute. A API deverá abrir uma documentação Swagger que você pode utilizar para listar, inserir, atualizar e excluir pessoas. Realize o login utilizando o usuário e senha admin:admin. Copie o token gerado, clique no botão Authorize, informe o token e realize a autenticação JWT.
